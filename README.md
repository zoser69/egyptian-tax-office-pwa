# دفتر المكتب الضريبي المصري (Egyptian Tax Office PWA — v14)

تطبيق ويب تقدمي (**PWA**) يعمل أوفلاين بالكامل (`Offline-First`) باللغة العربية (`RTL`) لإدارة العمل اليومي داخل مكتب المحاسبة والمراجعة الضريبية في مصر، مع حفظ مزدوج محلي ومزامنة سحابية فورية بين الأجهزة عبر **Supabase**.

## المميزات الأساسية (v14)
1. **سجل الممولين والحالات (مُحمّل مسبقاً بـ 21 ملف ممول — `SEED_CLIENTS_VERSION = 3`):**
   - متابعة المأمورية، النشاط، القسم والحالة (مع دعم إضافة أقسام وحالات مخصصة)، وتواريخ متعددة لكل ممول مع عدّاد تلقائي لمهلة الطعن الـ 30 يوماً (`hasAppeal30`)، وبحث لحظي (`Ctrl+K`)، وتصدير `CSV`، وطباعة تقرير المكتب (`A4`).
2. **أجندة الجلسات والتأجيلات والإشعارات:**
   - ربط الجلسات بالممولين وأرقام الطعون، ودعم التأجيل المتتالي غير المحدود مع حفظ خط زمني كامل (`history`)، وتنبيهات محلية بمواعيد الجلسات ومهلة الـ 30 يوماً عبر Web Notifications API.
3. **حاسبة الضرائب والفحص الشاملة (5 أدوات في شاشة واحدة):**
   - **مقارنة الفحص التقديري:** شرائح قانون 91 وتعديلاته عبر السنوات **2005–2026** (بما فيها قانون 7 لسنة 2024)، والشركات، والمادة 3 (ق 30/2023 حتى 10 مليون)، وقانون التسهيلات (6/2025 حتى 20 مليون)، مع رد الفترة الجزئية وكشف فخ «ضريبة الإقرار الأكبر» وخصم نموذج 41.
   - **الفاتورة والخصم (نموذج 41):** القيمة المضافة (`14%` ق 157/2025، `5%`، `0%`) والخصم من المنبع (`1%`, `3%`, `5%`, `20%` م 56، `0%`) على الصافي وتوليد قيد اليومية للبائع والمشتري.
   - **كسب العمل والتأمينات 2026:** حصة العامل (11%) والشركة (18.75%) ضمن حدود `2,700–16,700` ج، الإعفاء الشخصي `20,000` ج، الشريحة الصفرية `40,000` ج، وصندوق تكريم الشهداء (`0.05%`).
   - **التصرفات العقارية (2.5%):** مقارنة بالاستثمار العقاري، وتنبيه مهلة الـ **60 يوماً** (**قانون 151 لسنة 2026**) والاستثناءات.
   - **مقابل التأخير والمادة 87 مكرراً:** م 110 بسقف 100% (م 45 مكرراً ق 7/2025)، وإعفاء 30% وتخفيض م 87 للنصف قبل لجنة الطعن.
4. **موسوعة المراجع (25 مادة) ومولّد المذكرات القانونية (7 قوالب):**
   - صياغة آلية جاهزة للنسخ والطباعة (`A4`) لـ: طعن نموذج 19، طعن نموذج 15، طلب المادة 3، شهادة الموقف الضريبي، منازعة محضر الحجز الإداري، إخطار التوقف (نموذج 16 مكرر)، ومذكرة التقادم الخمسي.
5. **الحفظ المزدوج، التراجع، نقاط الاسترجاع، والمزامنة السحابية:**
   - حفظ تلقائي في `localStorage` و`IndexedDB` (`EgyptianTaxOfficeDB` v2)، مع `Undo/Redo` (30 خطوة، `Ctrl+Z` / `Ctrl+Y`)، ونظام `Checkpoints` شبيه بـ Git (50 نقطة)، وتصدير/استرجاع `.json`، ومزامنة ذرية مع **Supabase** (`tax_office_state` + `Realtime WebSocket`)، وقفل خصوصية للواجهة (`OFFICE_PIN`)، وService Worker بإصدار `egyptian-tax-office-pwa-v14`.

## إعداد Supabase ونبضة الاستمرار
1. افتح **Supabase SQL Editor** وشغّل محتوى ملف [`supabase_setup.sql`](supabase_setup.sql) مرة واحدة لإنشاء جدولَي `public.tax_office_state` و`public.tax_sync_commits`، وتفعيل `supabase_realtime`، وسياسات RLS، وTrigger التقليم التلقائي، ودالة `keep_project_alive()`، وبذر الـ 21 ممولاً.
2. ملف [`.github/workflows/supabase-keepalive.yml`](.github/workflows/supabase-keepalive.yml) يرسل نبضة كل 3 أيام (`0 8 */3 * *`) لمنع خمول المشروع المجاني.
